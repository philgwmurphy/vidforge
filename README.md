# VidForge

A modern, elegant FFmpeg GUI for video transcoding, editing, and batch processing built with Flutter.

## Platforms

- **Desktop**: Windows, macOS, Linux
- **Mobile**: iOS, Android

## Features (Planned)

### Video Operations
- Format conversion (MP4, MKV, WebM, MOV, AVI)
- Codec transcoding (H.264, H.265/HEVC, VP9, AV1)
- Lossless trimming and cutting
- Video compression with quality control
- Batch processing with queue management

### User Experience
- Intuitive preset system for common workflows
- Real-time progress tracking
- Drag & drop file handling
- Cross-platform consistency

## Documentation

- [Implementation Plan](./PLAN.md) - Comprehensive development roadmap and architecture

## Technology Stack

- **Framework**: Flutter 3.x
- **Language**: Dart 3.x
- **FFmpeg**: ffmpeg_kit_flutter_new (mobile) / bundled binaries (desktop)
- **State Management**: Riverpod
- **Architecture**: MVVM with Clean Architecture
